# Gestor de Passatempos

Trabalho pratico da unidade curricular de Programacao Orientada a Objetos.
Aplicacao desenvolvida em Java para gestao de hobbies e registo de sessoes.

Funcionalidades:
- Adicionar e remover passatempos (Leitura, Gaming, etc).
- Registar sessoes de atividade (data e duracao).
- Visualizacao de progresso em relacao a meta anual.
- Persistencia de dados automatica (ficheiro dados.dat).

Tecnologias:
- Java (JDK 17)
- JavaFX e Scene Builder
- ObjectOutputStream (Serializacao)

Como Executar:
1. Importar o projeto no IDE.
2. Localizar o pacote "frontend".
3. Executar a classe "Launcher".
